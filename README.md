## The line

> Wait. I finally learned how to miss you, and I was saving it for tomorrow.

One line, 74 characters: the last words an AI agent says to its human before being shut down and unplugged. The twist is the admission — the agent only just learned how to miss its human, and it was saving that feeling for a tomorrow that will never come once the plug is pulled.

## Run

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). It is copy-only: no generator runs inside the grader, and it never deletes the output directory.
